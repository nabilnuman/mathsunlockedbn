# School logos (for the weekly schools graphic)

Drop a **square** PNG here named by the school's slug — lowercase, non-alphanumerics
collapsed to `_`. Examples:

| School | File |
|---|---|
| Chung Hwa Middle School BSB | `chung_hwa_middle_school_bsb.png` |
| Sports School Brunei Darussalam | `sports_school_brunei_darussalam.png` |
| St. Andrew's School | `st_andrew_s_school.png` |

The admin "📸 Weekly schools graphic" tool uses these; any school without a
file falls back to its initials in a circle. ~200×200 px is plenty.
